# AGENTS.md

## Visual changes

When a change affects how the UI looks — layout, spacing, colour, typography, or a missing or broken style — include **before and after screenshots** in the pull request, one pair per affected screen and state.

- Capture both sides at the same viewport, theme, and state so the pair is directly comparable.
- Cover what the change touches: mobile and desktop, light and dark, and empty versus populated states.
- Label each pair clearly, e.g. **Before:** and **After:**.
